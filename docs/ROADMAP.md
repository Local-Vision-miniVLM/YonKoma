## フェーズ4 — 小さなサービス（任意）

**前提:** フェーズ1で自分が継続利用していること。

### 料金の現実

現行 Gemini 画像（5枚/回）の API 原価は **おおよそ 25〜35円/回**（為替・モデル依存）。

| 案 | 内容 |
|----|------|
| 無料 | 台本のみ / 月3本まで |
| ライト 500〜800円/月 | 月15〜30本 |
| 日記プラン 4000〜6000円/年 | 毎日1本（上限付き） |

**10円/回は原価割れ** → 回数制限・広告・スポンサー・高めの年額で補う。

### 差別化（売るもの）

- 汎用AI漫画ではなく **「日記の落ち」**
- **固定キャラ** の成長（同じシートで365日）
- **ラフ→清書** の儀式
- 積み上がった四コマのアーカイブ・振り返り

### やらないこと（初期）

- 動画工場（MiniMax H3 等は別プロダクト）
- 万人向けSNS巨大化
- ローカルSDのみの完全無料 SaaS（保守・品質で不利）

## 技術的決定の記録

| 決定 | 理由 | 日付 |
|------|------|------|
| 画像は4枚分割 | コスト・再生成・一貫性 | 2026-09 |
| セリフはHTML重ね | 修正容易 | 2026-09 |
| ローカル全面移行は見送り | 品質・一貫性・需要 | 2026-09 |
| Gemini を v0.1 デフォルト | 参照画像・速度・品質 | 2026-09 |
| 1650 Ti は試作機として活用 | 4GB VRAM でSD1.5可 | 2026-09 |
