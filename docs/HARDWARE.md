# ハードウェア評価

開発・利用想定マシンと、ローカル生成の現実性を整理する。

## 比較対象

| マシン | CPU | GPU | RAM | 役割案 |
|--------|-----|-----|-----|--------|
| A（開発中） | i7-1185G7 | Intel Iris Xe | 32GB | UI開発・台本（Ollama）・クラウドAPI |
| B（別PC） | （要確認） | GTX 1650 Ti 4GB | 32GB | ローカルSD試作・反復生成 |

## GTX 1650 Ti（4GB VRAM）の位置づけ

**四コマ漫画工場: 条件付きで YES**  
**動画工場: ほぼ NO**（短い低解像度の実験のみ）

### なぜ「条件付き」か

1650 Ti の強みは **CUDA が使える** こと。Iris Xe より画像生成は断然速い。  
弱点は **VRAM 4GB**。現代の SDXL・動画モデルのデフォルト設定には足りない。

### 四コマ漫画（静止画）— 現実的な設定

| 項目 | 推奨 |
|------|------|
| ベースモデル | SD 1.5（4.27GB級は分割ロード） |
| 解像度 | 512×512 または 384×512（4:3 コマ） |
| 高速化 | LCM-LoRA / HyperSD（4〜8 step） |
| 画風 | 鉛筆LoRA（例: Fisher Pencil Sketch） |
| 一貫性 | IP-Adapter（SD1.5）+ キャラシート参照 |
| 実行環境 | ComfyUI / Forge / FastSD CPU（CUDA） |
| WebUI 設定 | `--medvram` または `--lowvram` |

**体感目安（512px・LCM 4〜8 step）**

- 1コマ: 約 15〜45 秒
- キャラシート + 4コマ: 約 2〜5 分
- 再生成を含む試行錯誤: 10分前後も普通

**キャラ一貫性**

- Gemini 参照画像方式より **弱い** が、Iris Xe / CPU より **試行回数を稼げる**
- 日記四コマの「だいたい同じキャラ」には **足りる可能性が高い**
- プロ品質・多キャラ・細部の固定はクラウドAPIが依然有利

### 動画工場 — 厳しい理由

| 用途 | 4GB VRAM | コメント |
|------|----------|----------|
| AnimateDiff（SD1.5） | ギリギリ | 512px・短尺・フレーム数少なめ |
| Stable Video Diffusion | 困難 | 8GB+ が現実的 |
| MiniMax H3（33B） | 不可 | クラウド/API 専用 |
| 15秒 2K 動画 | 不可 | 別マシン or API |

「動画工場」を **メイン製品** にするなら 1650 Ti は不十分。  
**四コマ静止画の試作工場** として割り当てるのが合理的。

### RAM 32GB の価値

- Ollama（qwen2.5:14b 等）と SD を **同時常駐は非推奨**（VRAM+RAM競合）
- 使い分け: 台本生成時は SD を止める / 画像時は LLM を止める
- 32GB は **モデルキャッシュ・前処理** で十分余裕

## 結論

| 質問 | 答え |
|------|------|
| 1650 Ti で四コマ工場？ | **試作・反復向けには十分**。本番最高品質はAPI併用 |
| 1650 Ti で動画工場？ | **本格利用は非推奨**。実験1本程度 |
| Iris Xe より良い？ | **画像生成は明確に良い**。台本は両方ともOllama可 |
| YonKoma をBに置く？ | **ローカルSD検証用として有効**。メイン開発はAでも可 |
